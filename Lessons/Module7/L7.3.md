# Lesson 7.3: Downloading and Building the Linux Kernel

## Overview

Building a kernel is hours-of-beer-routine once you have the source and toolchain. This lesson walks from downloading `kernel.org` source to booting a kernel you compiled yourself.

## 1. Get the source

```bash
# Tarball from kernel.org
wget https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.12.tar.xz
tar xf linux-6.12.tar.xz && cd linux-6.12

# or via Git (shallow clone for size)
git clone --depth 1 --branch v6.12 \
    https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git
```

## 2. Configure

Start from a sane default, then tune interactively:

```bash
make defconfig          # or make x86_64_defconfig
make menuconfig         # full interactive config editor
```

`make localmodconfig` builds a config matching your current hardware — fastest path to a bootable kernel.

## 3. Build

```bash
make -j$(nproc)         # compile the kernel and modules (~10-40 min)
```

Common errors and fixes:

| Error | Fix |
|---|---|
| `flex: command not found` | `sudo apt install flex bison` |
| `no rule to make target` | missing deps, see Lesson 7.1 |
| Out of disk/memory | ensure ≥ 10 GiB free, reduce `-j` |

## 4. Install

```bash
sudo make modules_install
sudo make install       # installs kernel + initramfs into /boot
sudo update-grub        # regenerate boot menu
```

## 5. Boot and verify

Reboot, pick your new kernel in GRUB, then:

```bash
uname -r                # your (new) kernel version
dmesg | tail            # boot messages
```

## Exercise

Build `linux-next` or a stable release following the steps above, boot it, and confirm `uname -r` prints your custom build. Save a copy of your `.config` for future work.
