# Lesson 4.4: **Linux Package Management**
[![Linux Package Management](https://upload.wikimedia.org/wikipedia/commons/thumb/3/3b/Synaptic_screenshot.png/220px-Synaptic_screenshot.png)](https://en.wikipedia.org/wiki/Package_manager)

## Overview

Linux software is distributed as **packages**. A package manager installs, updates, and removes packages while resolving their **dependencies** automatically.

## Common Package Managers

| Distribution family | Package manager | Example commands |
|---|---|---|
| Debian / Ubuntu | `apt` | `apt install`, `apt remove`, `apt update`, `apt upgrade` |
| RHEL / Fedora | `dnf` (older: `yum`) | `dnf install`, `dnf remove`, `dnf update` |
| Arch Linux | `pacman` | `pacman -S`, `pacman -R`, `pacman -Syu` |

## Key Concepts

- **Repositories**: centralized servers that hold packages. `apt update` refreshes the local package index from repos defined in `/etc/apt/sources.list`.
- **Dependencies**: libraries and tools a package needs. Package managers fetch and install them automatically.
- **Broken packages**: occur when dependencies are missing or conflicting. Fixes include `apt --fix-broken install` and `apt install -f`.
- **Searching**: `apt search <term>` and `dnf search <term>` find packages by name or description.

## Common Tasks

```bash
# Update the package index
sudo apt update

# Upgrade all installed packages
sudo apt upgrade

# Install a package
sudo apt install vim

# Remove a package
sudo apt remove vim
```

## Exercise

1. Run `sudo apt update` (or your distro's equivalent) and note how many packages are available.
2. Search for a utility you use daily, install it, and confirm it works.
3. Uninstall it cleanly with your package manager and verify it is gone.
