# Lesson 4.2: **Basic Linux Commands**
[![Basic Linux Commands](https://upload.wikimedia.org/wikipedia/commons/thumb/b/b7/POSIX_Utilities.pdf/page1-191px-POSIX_Utilities.pdf.jpg)](https://en.wikipedia.org/wiki/Linux_commands)

## Overview

Master the commands you'll use daily: navigating the file system, working with files, managing processes, and inspecting the system.

## Navigating

```bash
pwd              # where am I
ls               # list files
ls -l -h         # long format with human-readable sizes
cd /etc          # change directory
cd ~             # go home
cd ..            # go up one level
```

## Working with files

```bash
cp source.txt dest.txt   # copy
mv old.txt new.txt       # move / rename
rm file.txt              # delete a file
mkdir -p a/b/c           # make directories (with parents)
touch notes.md           # create empty file
cat notes.md             # print file contents
less notes.md            # read a file page by page (q to quit)
```

## Managing processes

```bash
ps aux             # list running processes
top                # live process view
kill PID           # terminate a process by PID
kill -9 PID        # force terminate
jobs / bg / fg     # background and foreground control
```

## Monitoring the system

```bash
df -h              # disk space by filesystem
free -h            # memory usage
uname -a           # kernel version
whoami             # current user
```

## Getting help

```bash
man ls             # manual page for a command
ls --help          # quick usage summary
```

## Exercise

Open a terminal, create a working directory with `mkdir`, copy and move files between directories with `cp` and `mv`, then list everything with `ls -l` and check your disk space with `df -h`.
