# Lesson 5.3: **Signals and Their Uses**
[![yt-video](https://i.ytimg.com/vi/JWQfR_3ddYA/hq720.jpg)](https://www.youtube.com/watch?v=JWQfR_3ddYA)

## Overview

Signals let the kernel (or another process) send small, asynchronous notifications to a process. They are the classic Unix way to tell a running program "something happened" — immediately, whether the program asked or not.

## Common signals

| Signal | Meaning | Default action |
|---|---|---|
| `SIGINT` (2) | Interrupt — Ctrl+C at the terminal | Terminate |
| `SIGTERM` (15) | Polite request to terminate | Terminate |
| `SIGKILL` (9) | Forced termination | Terminate (cannot be caught) |
| `SIGSEGV` (11) | Invalid memory access | Terminate (core dump) |
| `SIGCHLD` (17) | A child process stopped/exited | Ignore |
| `SIGUSR1/2` | App-defined application signals | Terminate |
| `SIGALRM` (14) | Timer alarm | Terminate |

## Sending signals from the shell

```bash
kill -TERM 1234      # politely ask PID 1234 to stop
kill -9 1234         # force kill
kill -USR1 5678      # app-defined signal
```

## Catching signals in C

```c
#include <signal.h>
#include <stdio.h>
#include <unistd.h>

void on_alarm(int sig) {
    write(1, "alarm!\n", 7);
}

int main(void) {
    signal(SIGALRM, on_alarm);
    alarm(1);              /* kernel sends SIGALRM in 1 second */
    pause();               /* wait for any signal */
    return 0;
}
```

## Design notes

- Signals are **asynchronous**: they can arrive at any point in your program, so handlers must be re-entrant and avoid non-reentrant functions.
- Some signals can be **blocked or masked** temporarily; `SIGKILL` and `SIGSTOP` cannot be caught or ignored by design.
- The kernel delivers signals when the process next switches to user space, which is why signal delivery is tied to the scheduler's return-to-user path.

## Exercise

Run the example above and confirm "alarm!" prints after one second. Then use `kill -USR1` to send a signal to a small program you write, and observe the difference between catching `SIGTERM` (possible) and `SIGKILL` (impossible).
