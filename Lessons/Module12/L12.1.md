# Lesson 12.1: Understanding Kernel Security Vulnerabilities

## Overview

The kernel runs with full privileges, so a single bug can become a full system compromise. This lesson surveys the vulnerability classes and the realistic impact of each.

## Common vulnerability classes

- **Buffer overflows** — writing past a buffer's end corrupts adjacent memory; classic path to arbitrary code execution (e.g. in a driver parsing device input).
- **Use-after-free (UAF)** — touching memory after it was freed; a staple of `gadget` chains in kernel exploits (dangling pointers to `struct` anyway).
- **Race conditions** — two threads corrupt shared state without synchronization; famous for TOCTOU and refcount bugs.
- **Integer overflows** — size arithmetic wrapping to a wrong length → buffer issues.
- **Privilege escalation** — an exploit that takes a normal user/cgroup to root or to kernel code (`kernel-advisory` namespaces).
- **Information disclosure** — leaking kernel memory (side channels, uninitialized stack).

## Why the kernel specifically is a target

- Runs in ring 0 with all hooks.
- Massive attack surface: drivers, network protocols, filesystems all parse untrusted input.
- Bug fixes land slowly if the area is niche.

## Real-world consequences

- **Escalation**: CVE in a wifi/Bluetooth driver → code execution as root from a nearby malicious device.
- **Containment escape**: kernel bug → leap from a container to the host.
- **Boot compromise**: early-boot bugs (firmware/bootloader chains) give persistence before the security stack initializes.

## How the kernel defends itself

- Review discipline (`Reviewers`, security-relevant `Cc:`), `_GPL` licensing, `W=1` checks.
- Runtime mitigations (next lesson: ASLR, CFI, stack canaries, lockdown).
- `CONFIG_BUG_ON_DATA_CORRUPTION`, KASAN/UBSAN builds for testing.

## Suggested exercise

Pick a published kernel CVE from the last two years (e.g. a typical UAF). Read its fix commit and write a 5-line summary: bug class, the root cause, the fix, and the config/tool that would catch it.
