# Lesson 4.1: **Installing Linux**
[![Installing Linux](https://upload.wikimedia.org/wikipedia/commons/thumb/3/35/Tux.svg/150px-Tux.svg.png)](https://www.youtube.com/results?search_query=installing+linux)

## Overview

Linux runs on almost anything, and there are several ways to get it onto your machine. This lesson covers the three most common installation methods: bootable USB drives, virtual machines, and dual-boot setups.

## Key Concepts

- **Distributions**: "Linux" is the kernel; the full system is a distribution like Ubuntu, Fedora, Debian, or Arch.
- **Live environment**: Most installers boot a live desktop so you can test the OS before installing it.
- **Partitioning**: During install you decide where the OS lives — on an existing disk, a fresh partition, or a new disk entirely.

## Installation Methods

| Method | Use it when | Pros |
|---|---|---|
| Bootable USB | Installing to real hardware | Fast, full performance, works on any computer |
| Virtual machine (VM) | Trying Linux safely | Nothing on your main OS changes |
| Dual boot | Running both OSes on one machine | Native performance, no VM overhead |

### Bootable USB

1. Download the ISO from the distribution's website.
2. Write it to a USB stick. On Linux use `dd` or the graphical "balenaEtcher"; check the ISO's checksum first.
3. Boot from the USB, test the live environment, then click "Install".

```bash
dd if=ubuntu.iso of=/dev/sdX bs=4M status=progress
```

### Virtual Machine

Use VirtualBox or GNOME Boxes: create a new VM, attach the ISO as a virtual CD, and boot it as if it were a normal computer. The installer runs inside a window and your host OS is untouched.

### Dual Boot

The installer shrinks your existing partition and puts the Linux bootloader alongside your current OS. Your boot menu then lets you choose which OS to start.

## Exercise

Install Linux using a VM first (lowest risk), then decide whether you want a full USB install or dual boot on a spare machine.
