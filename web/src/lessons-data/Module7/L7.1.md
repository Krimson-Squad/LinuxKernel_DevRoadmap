# Lesson 7.1: Installing Development Tools

## Overview

Before touching the kernel you need a working toolchain. This lesson installs the compilers, build systems, and version control you'll use every day.

## Compilers

- **GCC** — the reference kernel compiler; supports C and (via `gcc-rs`/Rust) the newer Rust code paths.
- **Clang** — the LLVM compiler; the kernel team keeps Clang a fully supported alternative, useful for its static analyzer and nicer diagnostics.

Install on Debian/Ubuntu:

```bash
sudo apt install build-essential clang
gcc --version
clang --version
```

## Build tools

- **Make** — drives the kernel build (`make`, `make menuconfig`, ...).
- **CMake** — optional; handy for helper/user-space projects, the kernel itself uses Make + Kbuild.

```bash
sudo apt install make cmake
```

## Version control: Git

The Linux project lives in Git. Minimal daily workflow:

```bash
git clone <url> <repo>     # get a copy
git status                 # what changed
git add <file>             # stage
git commit -m "message"    # record
git checkout -b feature    # branch before changing things
```

## Live dependencies for building the kernel

Beyond the basics, a kernel build wants a few more packages:

```bash
sudo apt install flex bison libssl-dev libelf-dev libncurses-dev dwarves
```

## Verification

```bash
gcc --version && make --version && git --version
```

## Exercise

Install the tools above, clone a small repository, create a branch, make a change, and commit it. You now have the full driver's seat for kernel work.
